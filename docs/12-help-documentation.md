# 12. Help & Documentation

## 12.1 Manual Pages (`man`)

- **Concept:** Built-in documentation for commands and system calls.
- **Usage:** `man <command>` (e.g., `man ls`, `man chmod`).
- **Navigation:** Arrow keys, PageUp/PageDown, `/pattern` to search, `n` for next match, `q` to quit.
- **Sections:** `man` pages are divided into sections (e.g., 1=commands, 5=file formats, 8=admin commands). `man 5 passwd` for the file format.

## 12.2 Help Option (`--help`)

- **Concept:** Many commands provide a quick usage summary.
- **Usage:** `<command> --help` (e.g., `ls --help`, `grep --help`).

## 12.3 External Resources

- **explainshell.com:** Website that breaks down complex shell commands.
- Online search engines, distribution documentation, forums.
